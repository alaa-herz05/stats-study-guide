When is a situation Binomial?

A discrete distribution used to model experiments that satisfy: (1) the experiment has n trials; (2) each trial has two outcomes (or can be reduced to two): success (S) and failure (F) — win/lose, M/F, H/T, smoker/non-smoker, Jordanian/non-Jordanian, die: a 5 appears or does not; (3) P(S) = p and P(F) = 1 − p; (4) p is constant for all trials; (5) trials are independent. Then X = number of successes in the n trials, X ~ Binomial(n, p), x = 0, 1, …, n.

ذو الحدين: n محاولة، لكل محاولة نتيجتان (نجاح/فشل)، احتمال النجاح p ثابت، والمحاولات مستقلة. X عدد النجاحات وقيمه 0..n.

Formulas

P(X = x) = Cⁿₓ pˣ (1−p)ⁿ⁻ˣ for x = 0,1,…,n (0 otherwise), with Cⁿₓ = n!/(x!(n−x)!).
Mean (expected value): μ = np. Variance: σ² = np(1−p). Standard deviation: σ = √(np(1−p)).
Useful: Cⁿₙ = 1, Cⁿ₀ = 1. P(X ≥ 1) = 1 − P(X = 0).

القوانين: الاحتمال Cⁿₓ pˣ q^(n−x)، الوسط np، التباين np(1−p). ولـ (على الأقل واحد) نستخدم 1 − P(X=0).

Recall checklist

n trials · two outcomes · P(S)=p, P(F)=1−p · p constant · trials independent ⇒ X ~ Binomial(n,p).

قائمة التحقق: n محاولة، نتيجتان، p ثابت، استقلال.

Formulas

P(X=x) = Cⁿₓ pˣ (1−p)ⁿ⁻ˣμ = E(X) = npσ² = np(1−p)σ = √(np(1−p))P(X ≥ 1) = 1 − (1−p)ⁿP(X ≤ k) = Σ P(X=x), x = 0..k

Examples with full solutions (11)

Tap each question to reveal the solution.

Ex 1. X ~ Bin(6, 0.25). Find P(X=4), the mean and the variance

P(X=4) = C(6,4)(0.25)⁴(0.75)² = 15×0.00390625×0.5625 ≈ 0.0330 (file: 0.0329).
μ = 6(0.25) = 1.5. σ² = 6(0.25)(0.75) = 1.125.

Ex 2. Roll a fair die 5 times, X = number of 6s. Distribution, and P(no 6), P(at least one 6), P(at most one 6), P(2 ≤ X ≤ 4), mean, variance, SD

Conditions: 5 trials; S = 6 turns up; P(S) = 1/6; constant; independent → X ~ Bin(5, 1/6).
P(0)=0.4019, P(1)=0.4019, P(2)=0.1608, P(3)=0.0322, P(4)=0.0032, P(5)=0.0001.
No 6: 0.4019. At least one: 1 − 0.4019 = 0.5981. At most one: 0.8038. 2≤X≤4: 0.1608+0.0322+0.0032 = 0.1962.
μ = 5/6, σ² = 5(1/6)(5/6) = 25/36, σ = 5/6.

Ex 3. A coin is tossed 3 times. P(exactly two heads)? P(exactly four heads)?

X ~ Bin(3, 1/2): P(X=2) = C(3,2)(1/2)²(1/2) = 3/8. P(X=4) = 0 (impossible, x ≤ 3).

Ex 4. A die is tossed 4 times. P(at most 3 fives)

X ~ Bin(4, 1/6). P(X≤3) = 1 − P(X=4) = 1 − (1/6)⁴ = 1 − 1/1296 = 1295/1296.

Ex 5. A student guesses on a 10-question multiple-choice exam with 4 choices each. P(pass), i.e. at least 5 correct

X ~ Bin(10, 1/4). P(X ≥ 5) = 1 − [P(0)+P(1)+P(2)+P(3)+P(4)] ≈ 0.078.

Ex 6. X ~ Bin(n=4, p) and P(X=4) = 0.0256. Find p

C(4,4)p⁴(1−p)⁰ = p⁴ = 0.0256 → p = ⁴√0.0256 = 0.4.

Ex 7. X ~ Bin(n, p=0.6) and P(X < 1) = 0.0256. Find n

P(X=0) = C(n,0)(0.6)⁰(0.4)ⁿ = (0.4)ⁿ = 0.0256 = (0.4)⁴ → n = 4.

Ex 8. A die is rolled 480 times. Mean and variance of the number of 3s

X ~ Bin(480, 1/6). μ = 480/6 = 80. σ² = 480×(1/6)×(5/6) = 20/3.

Ex 9. X ~ Bin(n,p) with mean 5 and variance 4. Find n and p

np = 5 and np(1−p) = 4 → 5(1−p) = 4 → 1−p = 4/5 → p = 1/5. Then n(1/5) = 5 → n = 25.

Ex 10. A bent coin (P(head)=0.6) is tossed 4 times, X = heads. Distribution, μ and σ

X ~ Bin(4, 0.6): P(x) = C(4,x)(0.6)ˣ(0.4)⁴⁻ˣ, x = 0..4 → 0.0256, 0.1536, 0.3456, 0.3456, 0.1296 (sum 1).
μ = 4(0.6) = 2.4. σ² = 4(0.6)(0.4) = 0.96. σ = √0.96 = 0.98.

Ex 11. P(a student is accepted at a college) = 0.3. If 5 apply, P(at most 2 accepted)

X ~ Bin(5, 0.3). P(X≤2) = C(5,0)(0.7)⁵ + C(5,1)(0.3)(0.7)⁴ + C(5,2)(0.3)²(0.7)³ = 0.1681 + 0.3601 + 0.3087 = 0.84.

★ Key insight
Binomial = counting (Cⁿₓ) + independence (multiply probabilities) + a random variable (X counts successes). Every earlier chapter feeds this one. For ‘at least one’ always use the complement 1 − P(X=0).
ذو الحدين = عدّ (التوافيق) + استقلال (ضرب الاحتمالات) + متغير عشوائي (X يعدّ النجاحات). وللعبارة (على الأقل واحد) استخدم المتمم 1−P(X=0).
