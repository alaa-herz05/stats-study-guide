Relations between events

  1. Complement Ā (or Aᶜ): all elements in S but not in A (A does not occur).
  2. Union A∪B: all elements in A or in B or in both (at least one occurs).
  3. Intersection A∩B: all elements in both A and B (both occur together).
  4. Difference A−B: elements in A but not in B (A occurs and B does not).
  5. Disjoint (mutually exclusive): A∩B = ∅, no common elements (cannot occur together).
  6. Exhaustive events: A∪B = S.
  7. De Morgan laws: (A∩B)ᶜ = Aᶜ∪Bᶜ and (A∪B)ᶜ = Aᶜ∩Bᶜ.
  8. Distributive laws: A∩(B∪C) = (A∩B)∪(A∩C); A∪(B∩C) = (A∪B)∩(A∪C).

المتمم: كل ما في S وليس في A. الاتحاد: أو. التقاطع: و (معاً). الفرق: A ولا B. المتنافيان: لا يقعان معاً (A∩B=∅). الشاملان: A∪B=S. دي مورغان: متمم التقاطع = اتحاد المتممين، ومتمم الاتحاد = تقاطع المتممين.

General probability rules

  1. 0 ≤ P(A) ≤ 1
  2. P(S) = 1, P(∅) = 0
  3. P(Ā) = 1 − P(A)
  4. P(A∪B) = P(A) + P(B) − P(A∩B)
  5. P(A−B) = P(A∩B̄) = P(A) − P(A∩B); P(B−A) = P(B∩Ā) = P(B) − P(A∩B); P(Ā∩B̄) = 1 − P(A∪B)
For disjoint events P(A∩B) = 0, so P(A∪B) = P(A) + P(B).

القوانين العامة: المتمم 1−P(A)، الاتحاد P(A)+P(B)−P(A∩B)، الفرق P(A)−P(A∩B)، ولا هذا ولا ذاك 1−P(A∪B). للمتنافيين P(A∩B)=0.

Ex 1. Die: E₁={3}, E₂={3,4,5}, E₃={1,2,6}, E₄={1,2,4,5}, E₅={1,2,3,4}, E₆={2,4,6}. Find (1) E₁ᶜ (2) Ē₅ (3) Ē₄ (4) E₁∩E₂ (5) E₂∩E₃ (6) E₂∩E₆ (7) E₂∩E₅ (8) E₁∪E₂ (9) E₂∪E₅ (10) E₂−E₅ (11) E₄−E₃ (12) E₃−E₄ (13) two disjoint events (14) exhaustive events

S = {1,2,3,4,5,6}.
(1) E₁ᶜ = {1,2,4,5,6}, P = 5/6.
(2) Ē₅ = {5,6}, P = 2/6 = 1/3.
(3) Ē₄ = {3,6}.
(4) E₁∩E₂ = {3}, P = 1/6.
(5) E₂∩E₃ = ∅, P = 0.
(6) E₂∩E₆ = {4}.
(7) E₂∩E₅ = {3,4}.
(8) E₁∪E₂ = {3,4,5}, P = 3/6 = 1/2.
(9) E₂∪E₅ = {1,2,3,4,5}.
(10) E₂−E₅ = {5}.
(11) E₄−E₃ = {4,5}.
(12) E₃−E₄ = {6}.
(13) E₁ & E₃ (E₁∩E₃=∅), also E₂ & E₃ (E₂∩E₃=∅).
(14) E₂ & E₃ since E₂∪E₃ = S; also E₁, E₃, E₄ since E₁∪E₃∪E₄ = S.

Ex 2. P(A)=0.2, P(B)=0.7, P(A∩B)=0.15. Find P(B̄), P(A∪B), P(Ā∩B), P(Ā∩B̄), P(A−B)

P(B̄) = 1 − 0.7 = 0.3.
P(A∪B) = 0.2 + 0.7 − 0.15 = 0.75.
P(Ā∩B) = 0.7 − 0.15 = 0.55.
P(Ā∩B̄) = 1 − 0.75 = 0.25.
P(A−B) = 0.2 − 0.15 = 0.05.

Ex 3. P(A)=0.4, P(B)=0.35, P(A∪B)=0.5. Find P(A∩B)

0.5 = 0.4 + 0.35 − P(A∩B) → P(A∩B) = 0.75 − 0.5 = 0.25.

Ex 4. P(A)=2/3 and P(A−B)=5/12. Find P(A∩B)

P(A−B) = P(A) − P(A∩B) → P(A∩B) = 2/3 − 5/12 = 8/12 − 5/12 = 3/12 = 1/4.

Ex 5. A and B are disjoint, P(A)=0.7, P(B)=0.1. Find P(B−A) and P(A∪B)

P(A∩B)=0. P(B−A) = 0.1 − 0 = 0.1. P(A∪B) = 0.7 + 0.1 − 0 = 0.8.

Ex 6. S={e₁,e₂,e₃}, P(e₁)=0.3, P(e₂)=0.5. Find P(e₃)

P(S)=1 → 0.3 + 0.5 + P(e₃) = 1 → P(e₃) = 0.2.

Ex 7. P(A)=9/12, P(B)=3/4, P(A∩B)=2/4. Are A and B exhaustive?

Exhaustive means A∪B = S, i.e. P(A∪B) = 1.
P(A∪B) = 9/12 + 9/12 − 6/12 = 12/12 = 1 → yes, exhaustive.

Ex 8. Weather: P(rain)=50%, P(lightning)=40%, P(both)=20%. Find P(no rain), P(no lightning), P(rain or lightning), P(rain but no lightning), P(lightning but no rain), P(neither)

R = rain, L = lightning: P(R)=0.5, P(L)=0.4, P(R∩L)=0.2.
1) P(R̄) = 0.5.
2) P(L̄) = 0.6.
3) P(R∪L) = 0.5 + 0.4 − 0.2 = 0.7.
4) P(R∩L̄) = 0.5 − 0.2 = 0.3.
5) P(L∩R̄) = 0.4 − 0.2 = 0.2.
6) P(R̄∩L̄) = 1 − 0.7 = 0.3.

Ex 9. 630 patients: blood type O=284, A=258, B=63, AB=25. One patient is selected. Find P(A and AB), P(A or AB), P(not O)

E₁=O, E₂=A, E₃=B, E₄=AB: P(E₁)=284/630=0.4508, P(E₂)=258/630=0.4095, P(E₃)=63/630=0.1, P(E₄)=25/630=0.0397.
1) A and AB are disjoint: P(E₂∩E₄) = 0.
2) P(E₂∪E₄) = 258/630 + 25/630 − 0 = 283/630.
3) P(not O) = 1 − 0.4508 = 0.5492.

Ex 10. Venn diagram (A only 0.1, A∩B 0.3, B only 0.2, outside 0.4). Find P(A), P(B̄), P(A−B), P(A∪B)

1) P(A) = 0.1 + 0.3 = 0.4.
2) P(B) = 0.3 + 0.2 = 0.5 → P(B̄) = 0.5 (or 0.4 + 0.1).
3) P(A−B) = 0.1.
4) P(A∪B) = 0.4 + 0.5 − 0.3 = 0.6 (or 0.1 + 0.3 + 0.2).

Ex 11. Three-event Venn diagram: A only 0.13, A∩B 0.07, B only 0.10, B∩C 0.15, C only 0.28, outside 0.27. Find P(A), P(B−C), P(A∪C), P(exactly one event)

1) P(A) = 0.13 + 0.07 = 0.20.
2) P(B−C) = 0.10 + 0.07 = 0.17.
3) P(A∪C) = 0.20 + (0.15 + 0.28) = 0.20 + 0.43 = 0.63.
4) Exactly one = A only + B only + C only = 0.13 + 0.10 + 0.28 = 0.51 (the printed solution shows 0.45, which is an arithmetic slip).

★ Key insight
