How the chapters connect

  • 1. Measures of Center → Center tells you WHERE the data sits. Next chapter: HOW FAR it spreads around that center (variance, SD, C.V.).
  • 2. Measures of Dispersion → Chapters 1–2 describe data we already have. From chapter 3 we move to probability: describing outcomes we have not seen yet.
  • 3. Probability Concepts & Sample Space → Now that we can compute P(A), next we learn how events relate (union, intersection, complement) and the rules that combine their probabilities.
  • 4. Relations Between Events & Probability Rules → P(A∩B) is the key quantity in every rule above. Next: how knowing that B happened changes the probability of A, and when it does not (independence).
  • 5. Conditional Probability & Independence → Many probabilities are ratios of counts (n(A)/n(S)). Counting rules give us n quickly, without listing every outcome.
  • 6. Counting Rules → Counting gives us n(A) and n(S). Next we attach NUMBERS to outcomes: random variables and their probability distributions.
  • 7. Discrete Random Variables → The most important discrete distribution is built from repeated independent yes/no trials: the Binomial distribution (needs counting + independence + a random variable).
  • 8. Binomial Distribution → Congratulations: you covered descriptive statistics, probability, counting, random variables and the binomial model. Now test yourself in the Question Bank.

2. Measures of Dispersion

s² = Σ(x−x̄)² / (n−1)s² = [Σx² − (Σx)²/n] / (n−1)s = √s²s² (freq) = [Σx²F − (ΣxF)²/ΣF] / (ΣF−1)C.V. = (s/x̄)×100%SD(ax±b) = |a|·sVar(ax±b) = a²·s²

3. Probability Concepts & Sample Space

P(A) = n(A) / n(S)0 ≤ P(A) ≤ 1P(S) = 1 , P(∅) = 0P(A) = Σ P(e) , e ∈ ATwo dice: n(S) = 36

4. Relations Between Events & Probability Rules

P(Ā) = 1 − P(A)P(A∪B) = P(A)+P(B)−P(A∩B)P(A−B) = P(A) − P(A∩B)P(Ā∩B̄) = 1 − P(A∪B)Disjoint: P(A∪B) = P(A)+P(B)Exhaustive: P(A∪B) = 1

5. Conditional Probability & Independence

P(A|B) = P(A∩B) / P(B)P(A|B) = n(A∩B) / n(B)P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)Independent ⇔ P(A∩B) = P(A)·P(B)P(A|Bᶜ) = [P(A) − P(A∩B)] / [1 − P(B)]

6. Counting Rules

n₁·n₂·…·nₖn! = n(n−1)…2·1n!/(k₁!k₂!…kᵣ!)Pⁿₘ = n!/(n−m)! | nᵐ (with repl.)Cⁿₘ = n!/(m!(n−m)!) | C(n+m−1,m) (with repl.)P(event) = n(A)/n(S)

7. Discrete Random Variables

0 ≤ P(X=x) ≤ 1Σ P(X=x) = 1P(X ≤ a) = Σ P(X=x) , x ≤ aμ = E(X) = Σ x·P(x)σ² = Σ x²·P(x) − μ²

8. Binomial Distribution

P(X=x) = Cⁿₓ pˣ (1−p)ⁿ⁻ˣμ = E(X) = npσ² = np(1−p)σ = √(np(1−p))P(X ≥ 1) = 1 − (1−p)ⁿP(X ≤ k) = Σ P(X=x), x = 0..k
⚠ Important notes
  1. Disjoint ≠ independent.
  2. Before counting ask: does order matter? is repetition allowed?
  3. For ‘at least one’ use the complement.
  4. Compare spread with C.V. when means or units differ.
