Conditional probability

The probability that a particular event occurs given that another event has occurred. P(A|B) = probability of A given that B has occurred; P(B|A) = probability of B given that A has occurred.
P(A|B) = P(A∩B)/P(B), with P(B) ≠ 0. For counts: P(A|B) = n(A∩B)/n(B).

الاحتمال الشرطي هو احتمال وقوع حدث بشرط وقوع حدث آخر: P(A|B)=P(A∩B)/P(B) بشرط P(B)≠0، وبالأعداد n(A∩B)/n(B).

Multiplication rules

P(A∩B) = P(A|B)·P(B) and P(A∩B) = P(B|A)·P(A).

قاعدتا الضرب لإيجاد احتمال التقاطع.

Does knowing B change A?

  1. P(A|B) > P(A): knowing B increases the probability of A.
  2. P(A|B) < P(A): knowing B decreases the probability of A.
  3. P(A|B) = P(A): knowing B has no effect → A is independent of B.

ثلاث حالات: وقوع B يزيد احتمال A، أو يقلله، أو لا يؤثر (استقلال).

Independent events

A and B are independent if one of these holds: (i) P(A|B) = P(A); (ii) P(B|A) = P(B); (iii) P(A∩B) = P(A)·P(B). To test, check P(B|A) = P(B)? or P(A∩B) = P(A)P(B)?

الحدثان مستقلان إذا تحقق أحد الشروط: P(A|B)=P(A) أو P(B|A)=P(B) أو P(A∩B)=P(A)P(B).

Complements of independent events

If A and B are independent then so are: Ā and B̄ → P(Ā∩B̄) = P(Ā)P(B̄); Ā and B → P(Ā∩B) = P(Ā)P(B); A and B̄ → P(A∩B̄) = P(A)P(B̄).

إذا كان A و B مستقلين فمتمماتهما مستقلة أيضاً بكل الأشكال.

Formulas

P(A|B) = P(A∩B) / P(B)P(A|B) = n(A∩B) / n(B)P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)Independent ⇔ P(A∩B) = P(A)·P(B)P(A|Bᶜ) = [P(A) − P(A∩B)] / [1 − P(B)]

Examples with full solutions (8)

Tap each question to reveal the solution.

Ex 1. P(A)=0.3, P(B)=0.25, P(A∩B)=0.1. Find P(A|B)

P(A|B) = 0.1/0.25 = 0.4.

Ex 2. 339 persons by age (A₁ 20–29, A₂ 30–39, A₃ 40–49, A₄ 50+) and smoking (B₁ daily, B₂ occasionally, B₃ not at all). Row A₁: 31, 9, 7 (47). A₂: 110, 30, 49 (189). A₃: 29, 21, 29 (79). A₄: 6, 0, 18 (24). Totals 176, 60, 103 (339). Find: (1) aged 40–49 (2) smokes occasionally (3) 40–49 and occasionally (4) 40–49 or occasionally (5) not 50 or older (6) smokes daily given 30–39 (7) aged 20–29 given non-smoker

1) P(A₃) = 79/339.
2) P(B₂) = 60/339.
3) P(A₃∩B₂) = 21/339.
4) P(A₃∪B₂) = 79/339 + 60/339 − 21/339 = 118/339.
5) P(A₄ᶜ) = 1 − 24/339 = 315/339.
6) P(B₁|A₂) = n(B₁∩A₂)/n(A₂) = 110/189.
7) P(A₁|B₃) = 7/103.
Note: the printed table shows 19 in cell A₂,B₃, but row/column totals (189 and 103) require 49.

Ex 3. P(A)=0.3, P(B)=0.4, P(A∩B)=0.15. Find P(A|B), P(B|A), P(A|Bᶜ)

P(A|B) = 0.15/0.4 = 0.375 > P(A)=0.3.
P(B|A) = 0.15/0.3 = 0.5 > P(B)=0.4 (the printed text shows 6.5, a typo).
P(A|Bᶜ) = [0.3 − 0.15]/[1 − 0.4] = 0.15/0.6 = 0.4167.

Ex 4. A, B independent with P(A)=0.17, P(B)=0.3. Find P(A∩B), P(A|B), P(B|A), P(A∪B), P(A∩Bᶜ)

1) 0.17×0.3 = 0.051.
2) P(A|B) = P(A) = 0.17.
3) P(B|A) = P(B) = 0.3.
4) 0.17 + 0.3 − 0.051 = 0.419.
5) P(A) − P(A∩B) = 0.17 − 0.051 = 0.119.

Ex 5. P(A)=0.65, P(B)=0.32, P(A∩B)=0.13. Are A and B independent?

P(A|B) = 0.13/0.32 = 0.406 ≠ P(A)=0.65 → not independent (dependent). (Check: 0.65×0.32 = 0.208 ≠ 0.13.)

Ex 6. A fair coin is tossed 3 times. A = heads on first toss, B = two heads in total. Independent?

A = {HHH,HHT,HTH,HTT}, P(A)=4/8=1/2. B = {HHT,HTH,THH}, P(B)=3/8. A∩B = {HHT,HTH}.
P(B|A) = n(A∩B)/n(A) = 2/4 = 1/2 ≠ P(B)=3/8 → dependent.

Ex 7. A coin is flipped and a die is rolled. P(head and 5)?

A = head, B = 5; they are independent. P(A∩B) = 1/2 × 1/6 = 1/12.

Ex 8. Two men shoot a target independently: P(A hits)=1/3, P(B hits)=1/5. Find: A misses; both hit; at least one hits; none hits

1) P(Ā) = 1 − 1/3 = 2/3.
2) P(A∩B) = 1/3 × 1/5 = 1/15.
3) P(A∪B) = 1/3 + 1/5 − 1/15 = (5+3−1)/15 = 7/15.
4) P(Ā∩B̄) = 2/3 × 4/5 = 8/15.

★ Key insight
Disjoint ≠ independent! If A and B are disjoint with positive probabilities, knowing A occurred means B cannot occur, so they are dependent. Independence is about P(A∩B) = P(A)P(B); disjointness is about P(A∩B) = 0.
المتنافيان ليسا مستقلين! إذا كان احتمالاهما موجباً فهما معتمدان لأن وقوع أحدهما يمنع الآخر. الاستقلال: P(A∩B)=P(A)P(B)، والتنافي: P(A∩B)=0.
