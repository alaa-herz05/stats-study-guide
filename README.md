# Stats Study Guide

An interactive study guide covering core statistics, probability, and probability distributions, complete with a practice question bank and interactive features built using HTML, CSS, and JavaScript.

## Guide Contents

* **Home / Index (`00_Index.html`)**: Starting point for navigating across all study topics.
* **Measures of Center (`01_Measures_of_Center.html`)**: Review and notes on central tendency measures.
* **Measures of Dispersion (`02_Measures_of_Dispersion.html`)**: Review and notes on spread and dispersion measures.
* **Probability Concepts (`03_Probability_Concepts.html`)**: Foundational concepts and terminology in probability.
* **Probability Rules (`04_Probability_Rules.html`)**: Core probability laws and operations.
* **Conditional Probability & Independence (`05_Conditional_Probability_Independence.html`)**: Conditional probability and independent events.
* **Counting Rules (`06_Counting_Rules.html`)**: Combinatorics, counting principles, and arrangements.
* **Discrete Random Variables (`07_Discrete_Random_Variables.html`)**: Properties and distributions of discrete random variables.
* **Binomial Distribution (`08_Binomial_Distribution.html`)**: Study and applications of the binomial distribution.
* **Question Bank (`09_Question_Bank.html`)**: Practice questions to test understanding.

## Assets

* `assets/style.css`: Styling and layout for the study pages.
* `assets/app.js`: Core application logic and interactivity.
* `assets/fx.js`: Additional visual/interactive effects.

## Usage

1. Download or clone the repository to your machine.
2. Open `00_Index.html` in any web browser to browse locally, or host the files with GitHub Pages for live web access.
