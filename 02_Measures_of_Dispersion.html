Variance and Standard Deviation

The variance uses the mean as a point of reference.

  • Small when all observations are close to the mean.
  • Large when observations are spread out from the mean.
  • Zero (no variation) when all observations have the same value.
Sample variance: s² = Σ(xᵢ − x̄)²/(n−1) = [Σxᵢ² − (Σxᵢ)²/n]/(n−1).
The quantity xᵢ − x̄ is the deviation of the x value from the mean; the sum of deviations is always zero: Σ(xᵢ − x̄) = 0.
Standard deviation = √Variance = s. Both the variance and the SD cannot be negative.

التباين يستخدم الوسط كمرجع: صغير إذا اقتربت القيم منه، كبير إذا تباعدت، وصفر إذا تساوت كلها. الانحراف المعياري = الجذر التربيعي للتباين ولا يكونان سالبين أبداً، ومجموع الانحرافات عن الوسط = 0.

Variance of a Discrete Frequency Distribution

s² = Σ((xᵢ − x̄)²·F)/(ΣF − 1) = [Σ(xᵢ²·F) − (Σ(xᵢ·F))²/ΣF]/(ΣF − 1)

تباين التوزيع التكراري: نضرب كل قيمة بتكرارها F ونقسم على (مجموع التكرارات − 1).

Coefficient of Variation (C.V.)

Variance and SD measure variation of a single variable for a single population/sample. To compare the variation of two variables we cannot use them because: (1) the variables might have different units, (2) the variables might have different means, (3) we need a measure that does not depend on units or on how large the values are.
This measure is C.V. = (s / x̄) × 100%.
The 1st data set is more variable than the 2nd if C.V.₁ > C.V.₂, and vice versa.

معامل الاختلاف يقارن تشتت متغيرين مختلفين بالوحدات أو الأوساط. C.V.=(s/x̄)×100%. المجموعة ذات المعامل الأكبر تشتتها أكبر.

Examples with full solutions (8)

Tap each question to reveal the solution.

Ex 1. Compute the sample variance and SD of 5, 12, 6, 8, 14

x̄ = 45/5 = 9.
Deviations: −4, 3, −3, −1, 5 (sum 0). Squares: 16, 9, 9, 1, 25 → Σ = 60.
s² = 60/4 = 15, s = √15 = 3.87.

Ex 2. Same data, using s² = [Σx² − (Σx)²/n]/(n−1)

Σx² = 25+144+36+64+196 = 465, Σx = 45.
s² = (465 − 45²/5)/4 = (465 − 405)/4 = 15. s = 3.87.

Ex 3. A set of 6 numbers with Σx = 84 and Σ(x−x̄)² = 166. Find variance and SD

s² = 166/(6−1) = 33.2. s = √33.2 = 5.76.

Ex 4. A set of 10 numbers with Σx = 270 and Σx² = 9054. Find the variance

s² = (9054 − 270²/10)/9 = (9054 − 7290)/9 = 1764/9 = 196 (s = 14).

Ex 5. For 18 numbers, x̄ = 23 and s = 12. Find Σx and Σx²

Σx = 23·18 = 414.
s² = [Σx² − 414²/18]/17 → 144 = [Σx² − 9522]/17 → Σx² = 144·17 + 9522 = 2448 + 9522 = 11970.

Ex 6. Example 22: find the variance of x = 1,2,3,4 with frequencies F = 2, 9, 6, 8

x·F = 2, 18, 18, 32 → Σ = 70. x²·F = 2, 36, 54, 128 → Σ = 220. ΣF = 25.
s² = (220 − 70²/25)/24 = (220 − 196)/24 = 1.

Ex 7. Compare variability. Set 1: mean 66 kg, s 4.5 kg. Set 2: mean 36 kg, s 4.5 kg

C.V.₁ = 4.5/66 ×100 = 6.8%. C.V.₂ = 4.5/36 ×100 = 12.5%.
C.V.₁ < C.V.₂ → the second set has larger variability.

Ex 8. Sample 1, 3, 5 (mean 3, s 2, s² 4). Find the stats of −2x, x+10, and −2x+10

−2x: −2, −6, −10 → mean −6, SD 4, var 16.
x+10: 11, 13, 15 → mean 13, SD 2, var 4.
−2x+10: 8, 4, 0 → mean 4, SD 4, var 16.

★ Key insight
Equal standard deviations do NOT mean equal variability. 4.5 kg is small for a 66 kg group but large for a 36 kg group, so compare with the C.V.
